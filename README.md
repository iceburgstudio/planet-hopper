# Planet Hopper

Public pages for **Planet Hopper**, an iOS game by Iceburg Studio.

- **Privacy policy** — <https://iceburgstudio.github.io/planet-hopper/>
- **Support** — <https://iceburgstudio.github.io/planet-hopper/support/>

The game's source is not in this repository. This repo exists to host the
privacy policy and support page that the App Store listing links to, so both URLs
stay stable and publicly reachable without a sign-in.
